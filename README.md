To present two different UX project scenarios — **Campus Food Ordering App** and **Smart Travel Planner App** — by identifying user needs, analyzing problems, creating user personas and journeys, designing UX solutions, and evaluating the designs based on usability and user satisfaction.

## ALGORITHM:

1. **Select Scenarios**
   Choose two UX project scenarios: **Campus Food Ordering App** and **Smart Travel Planner App**.

2. **Identify Target Users**
   Define user groups such as college students, hostel residents, travelers, families, and first-time users, and understand their goals and requirements.

3. **Study Existing Systems**
   Observe existing food ordering and travel planning applications, analyze user interactions, and identify usability gaps.

4. **Collect User Problems**
   Use interviews, surveys, and observations to gather pain points faced by food-ordering users and travelers.

5. **Identify Major Pain Points**
   Highlight issues such as complicated navigation, unclear information, long waiting times, difficulty comparing options, and lack of timely feedback.

6. **Define Problem Statements**
   Frame clear problem statements for each scenario:

7. **Food Ordering Problem Statement**
   Students need a simple food-ordering app that allows them to quickly find food, customize orders, make payments, and track deliveries.

8. **Travel Planner Problem Statement**
   Travelers need an easy-to-use travel planning app that helps them discover destinations, organize itineraries, estimate expenses, and track their trips.

9. **Create User Personas**
   Develop personas representing typical users, such as **Arun – college student** and **Meera – frequent traveler**.

10. **Map User Journeys**
    Outline step-by-step journeys for each scenario, such as **select food → customize order → payment → track order → receive food** and **search destination → plan itinerary → check expenses → book → travel**.

11. **Generate UX Solutions**
    Propose design improvements such as simplified navigation, filters, live tracking, personalized suggestions, reminders, expense tracking, and clear feedback.

12. **Create Wireframes/Prototypes**
    Sketch basic layouts showing home screens, search pages, ordering screens, itinerary dashboards, payment pages, and tracking interfaces.

13. **Conduct Usability Testing**
    Ask users to perform tasks such as ordering food, tracking an order, creating a travel itinerary, and checking trip expenses. Record completion time, errors, and satisfaction.

14. **Collect Feedback**
    Gather user opinions on clarity, ease of use, navigation, accessibility, and overall satisfaction.

15. **Improve Design**
    Refine the designs based on feedback by simplifying menus, improving search and filtering, adding clearer status information, and reducing unnecessary steps.

16. **Finalize UX Solution**
    Confirm that the improved designs meet user needs and reduce major pain points.

17. **Evaluate Final Design**
    Assess the final designs based on usability, accessibility, simplicity, consistency, feedback, error prevention, and user satisfaction.

## SCENARIO 1: CAMPUS FOOD ORDERING APP

### 1. Overview

A campus food ordering app allows students to browse food available in college canteens, customize meals, place orders, make payments, and track their orders. The objective is to make campus food ordering quick, convenient, and easy to use.

### 2. Target Users

| User Group       | Main Requirements                        |
| ---------------- | ---------------------------------------- |
| College Students | Quick ordering and easy payment          |
| Hostel Students  | Food delivery to hostel/campus locations |
| Faculty Members  | Simple ordering and scheduled pickup     |
| First-Time Users | Clear navigation and instructions        |

### 3. User Goals

* Browse available food items
* Search and filter food
* Customize food orders
* Place orders easily
* Make digital payments
* Track order status
* Receive food on time

### 4. Major Problems

| Problem                   | Effect                    |
| ------------------------- | ------------------------- |
| Long queues at canteen    | Wasted time               |
| Unclear food availability | Order cancellation        |
| Complicated menus         | Difficulty selecting food |
| No live order status      | User uncertainty          |
| Multiple payment steps    | Abandoned orders          |

### 5. Problem Statement

Students need a simple campus food-ordering app that allows them to quickly find available food, customize orders, make payments, and track their orders without waiting in long queues.

### 6. User Persona

**Name:** Arun Kumar
**Age:** 20
**Occupation:** Engineering Student
**Goal:** Order food quickly between classes
**Needs:** Easy food search, quick payment, order tracking
**Pain Points:** Long canteen queues, unclear food availability, delayed orders

### 7. User Journey

**Open App → Browse Menu → Select Food → Customize Order → Add to Cart → Make Payment → Track Order → Collect Food**

### 8. Proposed UX Solution

* Simple home dashboard
* Food categories and search
* Availability indicators
* Customization options
* Quick payment process
* Live order-status tracking
* Pickup/delivery notifications

### 9. Usability Testing

Users attempt to search for food, customize an item, place an order, make payment, and track the order.

**Metrics:** Completion time, number of errors, task success rate, and satisfaction feedback.

### 10. Improvements

* Simplified food categories
* Added food availability indicators
* Reduced checkout steps
* Added live order tracking
* Introduced pickup notifications

## SCENARIO 2: SMART TRAVEL PLANNER APP

### 1. Overview

A smart travel planner app helps users discover destinations, create travel itineraries, estimate expenses, find transportation and accommodation, and manage their trips. The objective is to make travel planning simple, organized, and convenient.

### 2. Target Users

| User Group           | Main Requirements                     |
| -------------------- | ------------------------------------- |
| College Travelers    | Low-cost trip planning                |
| Families             | Safe and organized itineraries        |
| Frequent Travelers   | Quick itinerary management            |
| First-Time Travelers | Simple guidance and clear information |

### 3. User Goals

* Discover travel destinations
* Search attractions and activities
* Create personalized itineraries
* Estimate travel expenses
* Find transportation and accommodation
* Save important locations
* Receive travel reminders

### 4. Major Problems

| Problem                                  | Effect                        |
| ---------------------------------------- | ----------------------------- |
| Information spread across different apps | Difficult planning            |
| Complicated itinerary creation           | Confusion                     |
| Unclear travel expenses                  | Budget problems               |
| Missing booking information              | Travel uncertainty            |
| No reminders                             | Missed activities or bookings |

### 5. Problem Statement

Travelers need a simple travel-planning app that combines destinations, itineraries, expenses, bookings, and reminders in one place so that they can organize trips efficiently.

### 6. User Persona

**Name:** Meera Raj
**Age:** 26
**Occupation:** Software Professional
**Goal:** Plan short trips without spending too much time
**Needs:** Easy itinerary creation, budget tracking, booking information
**Pain Points:** Information scattered across apps, difficult expense tracking, complicated planning

### 7. User Journey

**Open App → Search Destination → Explore Places → Select Activities → Create Itinerary → Estimate Budget → Book Services → Receive Reminders → Start Trip**

### 8. Proposed UX Solution

* Personalized destination suggestions
* Search and category filters
* Drag-and-drop itinerary planning
* Automatic expense summary
* Centralized booking information
* Travel reminders and notifications
* Offline access to saved itinerary

### 9. Usability Testing

Users attempt to search for a destination, add attractions to an itinerary, check the estimated budget, and access booking information.

**Metrics:** Task completion time, errors, task success rate, and satisfaction feedback.

### 10. Improvements

* Simplified itinerary creation
* Added destination filters
* Introduced automatic budget calculation
* Added centralized booking details
* Added travel reminders and notifications
